# 构美完整流程

根据《构美流程.pdf》，在原 `20261116wan3.0口播视频复刻_（去除人脸+黑色遮罩+去除字幕）` 工作流基础上整理。原文件保留不覆盖。所有 JSON 均可拖入 ComfyUI。

## 规整版主流程本次更新

本节适用于 `构美_全流程_规整版.json`，仅更新单人／单人＋画外音的完整流程。其余分阶段 JSON 和双人模板保持原版，后文的分阶段操作说明仍适用于它们。

主流程现为自动版：上传素材后，只需在 `构美｜选择场景` 选择“单人口播”或“单人＋画外音”。服饰选定、角色分析、台词改写、时间分配及音色路由自动连接；无需填写商品资料、复制台词 JSON 或开启 `confirmed`。自动台词只依据可见服饰事实，不编造价格、成分比例或功效。场景同步到分析、参考图编排和台词节点；双人口播继续使用独立原版模板。

自动报告与结果预览保留。单人＋画外音的角色判断缺乏口型证据时，相关发言按画外音处理并记录不确定项；模型判断仍可能出错。缺少说话者音色、没有两张可信 LOGO 特写等素材问题仍会报错，不会以重复图或虚构素材继续。下载文件保留用户已有素材选择、布局和缩放子图；仓库与服务器模板使用素材占位符。

- 初始素材：同一模特的 3 张原图、目标服饰的 5 张原始资产图。
- Wan2.7 Pro 正面图接收 3 张模特图＋5 张服饰图；背面图接收生成的正面图＋5 张服饰图。
- Qwen3.0 Pro 面部特写只接收 3 张模特原图。
- Qwen3.8 Max 分析带原图编号的服饰预览，选择与确认单品匹配、文字清晰的两张 LOGO／文字特写。选择节点输出五张输入中对应的原图，不生成或裁剪 LOGO。
- 最终 Wan3 图片固定为 5 张：图片1正面、图片2背面、图片3面部、图片4／5为所选原始服饰细节。编排时等比缩放并补白边，仍为五张独立图片。分析拼图只供视觉分析，不发送给 Wan3。
- 新增 `Video Preprocess Remove Audio`，静音输出直接接到 Wan3；ASR 和角色分析仍读取原始片段音轨。
- 为避免大图重新编码为 PNG 后超过 API 的单图大小限制，8 张初始素材、3 张 AI 图的后续参考分支和最终 Wan3 五图批次均接入 KJ `Resize Image v2`：宽高设为1024、`keep_proportion=resize`、`lanczos`、`divisible_by=1`、`device=cpu`。最长边为1024，保持原比例、不裁切；生成图保存分支仍保留原分辨率。需安装 `comfyui-kjnodes`。LOGO 选择保留原始资产内容，但传给模型的是等比缩小后的版本。

自动选图不能保证每次准确，也不能从缺少细节的素材中还原真实 LOGO。请查看两张选图预览及报告：不足两张可信特写时流程报错，不会重复或生成图片凑数；可更换资产，或目视确认后在选择节点的 `manual_indices` 填两个不同的原图编号，例如 `[2,5]`。手动编号只覆盖选图结果，上游素材分析仍会执行。

新增节点：`GoumeiAnalysisSheet`（带编号分析预览）、`GoumeiSelectLogoDetails`（从五张原图选择两张 LOGO 细节）、视频预处理仓库的 `Video Preprocess Remove Audio`。旧静音节点保留，供原版分阶段流程继续使用。

已使用真实 Qwen 接口对五张人工构造的服饰测试图验证，正确选出第2／5张特写；这不等于已用你的真实素材跑通整段成片。运行前仍需选择素材，自动版无需人工确认替换对象和台词。

## 推荐运行顺序

| 文件 | 用途 | 运行前填写 |
| --- | --- | --- |
| 构美_01_素材识别与台词确认 | 服饰/logo 识别、原片 ASR、结合口型判断角色、按卖点生成候选台词 | 原片、服饰参考、真实商品资料；Video Slice 的起点和片段长度 |
| 构美_02_角色三图_Wan27_Qwen30 | 每个角色生成正面、背面、脸部三张基础参考 | 最初的人物图、已选服饰、确认替换对象及携带方式 |
| 构美_03_视频制作_单人口播 | A 出镜并说话 | A 的三图、音色、原片与确认台词 |
| 构美_03_视频制作_单人＋画外音 | A 出镜，B 画外音；也支持全程只有 B 发言 | A 的三图、A/B 音色、原片与确认台词 |
| 构美_03_视频制作_双人口播 | A、B 都出镜 | 分别用 02 生成 A/B 三图，加载六图及两个音色 |
| 构美_04_分段视频拼接 | 按顺序拼接已生成的片段，并保留各段声音 | 按时间顺序加载成片，接入动态 video 插口 |
| 构美_全流程_规整版 | 查看并运行全部连接，默认 A＋画外音 | 各阶段素材、确认台词；首次建议分阶段运行 |

原工作流引用的旧图片、视频、音频没有打包。所有加载节点均使用明确的占位文件名，请重新选择自己的素材。原有服装与人物多角度图可以接入生成节点的动态参考图插口；Qwen3.0 总共最多 3 张人物图，Wan2.7 最多 9 张。

主图保留六个有编号的区域和中文标题，排队后自动运行付费分析、生图和视频制作。分阶段模板仍采用手动方式：阶段 03 的 `confirmed` 默认关闭、台词为空，填写并确认后再开启 `confirmed` 输出给 Wan3。

## 模型与三图依赖

- 正面：`wan2.7-image-pro`，异步、1 张、1536×2048。
- 背面：`wan2.7-image-pro`，**图片1直接连接生成的正面图**；图片2是原始服饰素材。可以继续加明确的背面素材。
- 人脸：`qwen-image-3.0-pro`，OpenAI 兼容、1 张、1024×1024，**只连接最初的人物参考图**，不连接服饰图或无脸穿搭图。
- 服饰识别、角色判断与原片视觉分析：`qwen3.8-max`。
- 视频：`wan3.0-video`，720P、9:16、`enhance_prompt=Disabled`，按片段时长向上取整。例如原片 13.7 秒，成片和台词时间上限为 14 秒。

三图生成后请检查身份、服饰、鞋底和背面的一致性。阶段 02 可对 A/B 分别运行；B 的保存前缀改为 `Goumei/B_front`、`B_back`、`B_face`。固定 seed 可复用缓存；需要重做某张时只修改对应生成节点的 seed。

## 确认服饰与 logo

识别结果是建议，单图多件或类别不明时必须先选择替换对象，把结果填到“已确认替换对象及身体侧别”。不把识别结果直接当作确认，不自动猜测包背哪侧。

原始清晰 logo/文字特写需要在阶段 03 **额外连接**到“构美｜参考图编排”的 `extras.image0` 等插口，并填写相同顺序的 `extra_labels`：

```json
["A 外套左胸 logo 原始特写", "原片同款商品包装细节", "目标背景参考"]
```

额外图不会被默默丢弃。A 三图固定为图片1/2/3；双人场景 B 三图固定为图片4/5/6；其后才是额外细节图。所有图片合计最多10张；不允许把普通面料、口袋图自动当成 logo 特写。本工作流保留人工确认后的原图，未将模型的 logo 判断自动变成上传授权。

参考图进入视频前统一等比缩放、白边补齐到1536×1536，便于合成 IMAGE batch，不拉伸人物和商品。每张仍是独立参考，未合成一张拼图。

## 角色、台词与音色

先核对 ASR，再结合原片口型确认 A/B。ASR 的说话分组不是出镜者/画外音身份。保留原文时按实际角色填写原台词；使用自备稿时直接填写；采用候选改写稿时先核对商品事实和角色顺序。

在“构美｜确认台词与音色路由”填写：

```json
[
  {"role": "B", "text": "这里填写已经确认的画外音台词"},
  {"role": "A", "text": "这里填写已经确认的出镜者回答"}
]
```

开启 `confirmed` 后，程序按字数分配连续时间、合并相邻同角色发言，并报告推荐字数范围和实际字数。可选择“保留确认时间”，给每段增加 `start`、`end` 秒数，允许停顿但不允许重叠。时间一律从当前片段的0秒开始。

音色只传给实际发言的角色。A/B 都发言时 A=音频1、B=音频2；只有 B 发言时 B=音频1、第二个音频为空，提示词明确 A 不发声、不做口型。A/B 源音频默认各裁6秒，总计12秒，符合15秒总参考音频限制。PDF 上传阶段要求提供 A 音色，这里保留 A 加载卡；最终不传未发言者音色。

确认台词由程序直接拼入最终提示词，不再交给模型重写。最终提示词包含图号映射、可见服饰与接触关系、去除旧物、身体左右约束、保留商品、实际音频编号及逐句时间。

## 视频预处理与长视频

沿用原工作流的字幕检测/处理、人脸黑色遮罩及预览；新增参考视频静音。

- `Video Slice` 先裁出2–15秒片段；阶段01与03的起点、长度要相同。
- ASR、角色判断和最终视觉分析均连接**原始片段**，不会用糊脸视频判断口型或接触关系。
- 字幕定位改为每秒1帧；13.7秒片段约检测14帧。默认本地字幕模糊，原有 IMS 擦除选项仍可用。
- 黑色人脸遮罩保留；失败策略改为 `error`，不会在检测失败时悄悄继续。原节点的 `prompt_hint` 已接入最终提示词，目标人脸为图片3；双人则各用图片3/6。
- 只发给 Wan 的参考视频静音，原片分析分支保留原音轨。
- 长片按2–15秒分段运行03，每段单独确认台词，完成后用04拼接。这是显式分段，不是无人值守自动批量任务。

## 与 PDF 的实现差异

保留已有节点的 ASR `qwen-audio-3.1-asr-flash-filetrans`，未替换为 PDF 中的 `fun-asr`。人脸检测沿用已安装 Video Preprocess 的 BlazeFace/YuNet，而不是另外下载 SCRFD。字幕沿用本地模糊/IMS，而不是新增白框遮挡。三者均保留旧工作流已经具备的处理路径。

角色/单品确认、原始 logo 的采纳及时间审核由用户完成；ComfyUI 未新增素材卡片 Web 页面。三个场景均有独立模板，阶段03“参考图编排”和“台词路由”的场景必须一致。

## 依赖与验证范围

需要本仓库最新版、ComfyUI-LLM、ComfyUI-Wan3.0-API、ComfyUI-Video-Preprocess，以及支持 V3/Autogrow 的当前 ComfyUI。新工作流使用核心字符串和视频节点，去掉了旧图多余的逐图缩放与分组 bypass 依赖。静音使用系统 FFmpeg 或 `FFMPEG_PATH`。

图像密钥读取本插件本地配置；文字/视觉/ASR、字幕处理、Wan3 继续读取各自插件已有配置。Wan3 应配置 `provider=bailian` 以及已有 OSS 凭证；密钥均不写入 JSON 工作流。

已进行图像接口真实付费测试、逻辑测试及 ComfyUI 原生 prompt 连线校验。工作流模板未使用你的真实人物、服饰、音色和确认台词跑完整视频；需要选择素材并确认后执行。
